# Codex 指令：将小刘实验室首页改为「专题化」结构

## 背景

当前 VitePress 文档站首页主要围绕「微信支付接入实验室」展开。

现在需要调整定位：

* 整站品牌：小刘实验室
* 核心理念：每一个第一次，都值得跑通
* 当前第一个专题：微信支付实验
* 微信支付实验下包含：

  * Native Pay MVP
  * JSAPI Pay MVP（整理中）
  * Code Pay MVP（整理中）

VitePress 本身没有内置“专题”概念，请使用目录 + 首页 + sidebar/nav 的方式实现专题结构。

---

## 目标

将文档结构调整为：

```text
docs/
  index.md
  wechat/
    index.md
    native-pay-mvp/
      index.md
    jsapi-pay-mvp/
      index.md
    code-pay-mvp/
      index.md
```

如果当前已有：

```text
docs/wechat/native-pay-mvp/index.md
```

请保留现有内容，不要覆盖。

---

## 修改要求

### 1. 修改站点首页 `docs/index.md`

首页定位为「小刘实验室」，而不是单独的微信支付文档站。

首页文案方向：

```yaml
hero:
  name: 小刘实验室
  text: 每一个第一次，都值得跑通
  tagline: 面向开发者的最小 MVP 实验室。每个实验都以「在线体验 + 可运行源码 + 明确成功结果」为目标。
```

首页 actions 至少包含：

```yaml
actions:
  - theme: brand
    text: 微信支付实验
    link: /wechat/
```

features 展示实验室方向，例如：

* 微信支付实验
* 第一次 Native Pay
* 第一次 JSAPI Pay
* 第一次 Code Pay
* 第一次买域名（Coming Soon）
* 第一次买云服务器（Coming Soon）

注意：不要让首页看起来像“微信支付文档站”，而是让微信支付成为第一个专题。

---

### 2. 新增 `docs/wechat/index.md`

这是「微信支付实验」专题首页。

页面使用 `layout: home`。

建议文案：

```yaml
hero:
  name: 微信支付实验
  text: 从第一次付款成功开始
  tagline: Native Pay、JSAPI Pay、Code Pay 的最小 MVP 实验。先跑通，再理解。
```

actions：

```yaml
actions:
  - theme: brand
    text: Native Pay MVP
    link: /wechat/native-pay-mvp/
  - theme: alt
    text: JSAPI Pay（整理中）
    link: /wechat/jsapi-pay-mvp/
  - theme: alt
    text: Code Pay（整理中）
    link: /wechat/code-pay-mvp/
```

features 包含：

* Native Pay：电脑页面生成 code_url，微信扫码支付
* JSAPI Pay：公众号内网页拉起微信支付
* Code Pay：扫码用户付款码完成支付
* 支付回调：处理微信支付通知
* 订单查询：根据 out_trade_no 查询订单状态
* 常见问题：notify_url、公网 HTTPS、匿名访问等排查

正文包含：

```md
## 这个专题适合谁？

适合第一次接入微信支付，或者想快速跑通 Native Pay / JSAPI Pay / Code Pay 最小流程的 Java / Spring Boot 开发者。

## 推荐实验顺序

1. Native Pay MVP：先理解创建订单、生成 code_url、查询订单、处理回调。
2. JSAPI Pay MVP：再理解 openid、prepay_id 和前端拉起支付。
3. Code Pay MVP：最后理解付款码支付和扫码枪场景。
```

### 4. 修改 VitePress 配置

修改 `.vitepress/config.ts` 或当前实际配置文件。

要求：

#### nav

增加或调整为：

```ts
nav: [
  { text: '首页', link: '/' },
  { text: '微信支付', link: '/wechat/' },
]
```

#### sidebar

使用路径分组：

```ts
sidebar: {
  '/wechat/': [
    {
      text: '微信支付',
      items: [
        { text: '专题首页', link: '/wechat/' },
        { text: 'Native Pay MVP', link: '/wechat/native-pay-mvp/' },
        { text: 'JSAPI Pay MVP（整理中）', link: '/wechat/jsapi-pay-mvp/' },
        { text: 'Code Pay MVP（整理中）', link: '/wechat/code-pay-mvp/' },
      ],
    },
  ],
}
```

如果当前配置是数组形式，请改成对象形式，确保 `/wechat/` 路径下能显示专题 sidebar。

---

## 注意事项

1. 不要删除现有 Native Pay 文档内容。
2. 不要改坏已有可访问路径 `/wechat/native-pay-mvp/`。
3. 首页不显示 sidebar 是正常的，不需要强行显示。
4. 专题页 `/wechat/` 也可以使用 home layout，主要用于引导。
5. 所有链接统一使用尾部 `/`。
6. 修改完成后，确保本地 `npm run docs:dev` 或项目实际启动命令可以正常启动。
7. 如果项目中已有不同的 docs 目录或配置路径，以当前项目实际结构为准。
