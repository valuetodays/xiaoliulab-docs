# 同一个指数，两种买法：ETF和联接基金怎么选？

想投资沪深300，上网一查，有人推荐“沪深300ETF”，也有人推荐“沪深300ETF联接”。名字很像，跟踪的又是同一个指数：它们究竟有什么区别？

最值得先弄清楚的，不是哪一个收益更高，而是**买入以后，我实际持有什么，又是怎样买卖的？**

## 先搞清楚：它们是什么关系

以股票型ETF为例，**ETF**是一只在证券交易所上市的基金，按照指数规则持有一篮子股票。投资者可以像买卖股票一样，在交易所买卖它的份额。

**ETF联接基金**是另一只基金。它将不低于基金资产净值90%的资金投资于对应的目标ETF，剩余部分用于现金管理等。买入联接基金，相当于通过另一只基金间接投资目标ETF。

打个比方：ETF像是自己去批发市场买东西，联接基金像是参加小区团购，由团长集中采购。最终拿到的是同一批商品，只是中间多了一层安排。

但“同一批商品”不等于“完全相同”：**ETF与联接基金是两只独立的基金，各有自己的份额、净值、费用和分红规则。**

常听到的“场外ETF”，通常指的就是ETF联接基金。严格来说，联接基金不是ETF，也不等于所有场外指数基金。

## 区别一：怎么买、怎么卖？

**场内ETF**通过证券账户，在交易所交易时间内买卖。它有实时的市场价格，但挂单不代表一定成交，结果取决于当时的买卖盘和流动性。多数境内股票ETF实行T+1交易，部分债券、黄金和跨境ETF等品种可以T+0，具体看品种规则。卖出后资金通常很快可用。

**联接基金**通过银行、券商、基金公司或互联网基金销售平台申购和赎回。交易日15:00前提交的有效申请，通常按当日收盘后计算的净值确认；超过时间则顺延到下一个交易日。

这叫“未知价交易”：下单时还不知道成交净值。赎回款到账也比场内卖出慢，具体时间看基金和销售渠道。

这里要纠正一个常见的误解：**不是“证券软件只能买ETF、支付宝只能买联接基金”。** 券商同样可以销售场外基金。真正的区分是“场内交易”和“场外申购赎回”，而不是打开了哪个App。

## 区别二：费用是怎样产生的？

**场内ETF**直接交易的成本主要是券商佣金，实际成交还会受到买卖价差影响。管理费、托管费会持续从基金资产中扣除，体现在净值里。

**联接基金**可能涉及申购费、赎回费、销售服务费，同时也有自己的运作费用。不同份额类别的收费方式不同。联接基金投资目标ETF的那部分资产，通常在基金合同中约定不再重复计提管理费、托管费，所以不会出现“两层费用叠加”。

因此，比较成本不能只看某一项。更实用的做法是：**把申购费、赎回费、服务费、佣金和价差，按自己打算持有的时间折算到一起比较。**

### 联接基金的A类和C类怎么选？

不少联接基金同时设有A类和C类。它们属于同一只基金，投资目标和资产组合一致，只是收费方式不同，所以各自公布的净值也会略有差异。可以把它想成手机套餐：

- **A类**像“一次性买断”：通常在申购时收取申购费，不另收销售服务费。
- **C类**像“按天计费”：通常不收申购费，但在持有期间每天计提销售服务费，体现在净值里，看不到账单。

两类份额都可能涉及赎回费，具体费率以产品公告为准。

过去常见的经验是“长期选A，短期选C”。但这条经验正在被新规改变：**自2026年1月1日起施行的《公开募集证券投资基金销售费用管理规定》明确，对持有期限超过一年的非货币市场基金份额，不再收取销售服务费。** 这意味着C类长期持有的“服务费越积越多”的劣势，会随着新规落地而减弱。至于存量基金具体何时调整、如何执行，以基金管理人的公告为准。

所以，选A还是C，不要只看名称后面的字母，可以按三步来：

1. **看持有期限**：打算持有不到一年，C类不收申购费，通常更占优；持有时间更长，要看新规在该基金上如何落地，再比较两类的总成本。
2. **看购买渠道**：同一只基金在不同渠道，申购费折扣可能不同，部分基金公司的直销渠道也在调整申购费，价格不一定一样。
3. **看费率页**：打开基金详情页，对比申购费折扣、销售服务费率和赎回费档位。

## 区别三：交易价格与基金净值

ETF在交易所买卖，存在**市场价格**和**基金份额净值**两个概念。

假设某ETF每份净值1.00元，市场成交价是1.02元，高出净值的部分叫“溢价”；如果成交价是0.98元，就是“折价”。

这种偏离受供需、申购赎回机制和底层市场交易情况影响。对于某些跨境ETF，尤其要留意高溢价：即使跟踪的指数没有下跌，溢价回落也可能带来亏损。

联接基金通过场外渠道申购赎回，按净值确认份额，所以**不存在二级市场交易价格带来的折溢价**。不过，它持有的目标ETF本身有市场价格和净值，二者的差异可能间接影响联接基金的运作结果。

## 区别四：定投和分红复投

想每月投入几百元，联接基金通常更方便：许多销售平台支持小额自动定投，设好周期和金额，到期自动扣款申购。

场内ETF也可以定期买入，部分券商提供自动定投功能，是否支持、如何执行要看券商。场内交易还受最小交易单位限制，常见为100份的整数倍。

分红方面：

- **场内ETF**通常是现金分红。想继续投入，需要自己再买入，或使用券商支持的自动交易功能。
- **联接基金**通常可以选择现金分红或红利再投资。选择再投资后，分红会按规则自动转为新增份额，不必每次手动买入。具体选项和默认方式以基金合同和销售页面为准。

还有一点容易误会：**目标ETF分红，不等于联接基金同一天、按相同比例向你分红。** 联接基金有独立的收益分配安排。

另外，无论哪种方式，分红都不是凭空增加的财富：现金分出去之后，净值会相应下调。想比较长期结果，应该看包含分红再投资在内的总回报。

## 其他差别，放在一张表里

| 比较项目 | 场内ETF | 场外持有的ETF联接基金 |
| --- | --- | --- |
| 实际持有 | ETF份额 | 联接基金份额 |
| 主要交易方式 | 交易所撮合买卖 | 按规则申购、赎回 |
| 成交价格 | 盘中市场成交价 | 按适用交易日的基金净值确认 |
| 常用购买渠道 | 证券账户 | 银行、券商、基金公司、基金销售平台 |
| 起购门槛 | 通常按100份整数倍交易 | 通常支持较小金额申购 |
| 直接费用 | 佣金、买卖价差等 | 申购费、赎回费、销售服务费等，依份额类别而定 |
| 分红后继续投资 | 通常需再次买入 | 通常可选择自动红利再投资 |
| 交易灵活性 | 交易时间内可挂单、撤单 | 按基金申赎确认规则执行 |
| 跟踪误差 | 以基金披露数据为准 | 以基金披露数据为准，还受联接基金现金管理等因素影响 |

**别凭“ETF的跟踪误差一定更小”来选。** 买之前，查看具体产品披露的跟踪误差、费用和历史表现。

## 还有一个容易忽略的因素：交易方式会影响行为

场内ETF随时能看到价格、随时可以尝试交易，对想灵活买卖的人很方便；但对容易被短期涨跌吸引的人，也可能带来不必要的频繁交易。

联接基金按未知价申赎，没办法盯着盘中价格反复买卖。这个限制可能帮部分人减少临时操作，但不意味着它会自动让人长期持有。

工具不只决定交易规则，有时也会悄悄影响使用者的习惯。

## 到底怎么选？

先想清楚你要怎么使用这笔钱，再对号入座。

**场内ETF更适合：**

- 有证券账户，希望盘中交易、自己控制挂单价格
- 想用特定品种的T+0机制
- 对价差、流动性有判断，愿意自己盯一盯

**联接基金更适合：**

- 小额定投，不想经常看行情
- 没有证券账户，或者更习惯在基金平台操作
- 希望分红按规则自动再投资

如果选了联接基金，再按前面的三步选A还是C：持有多久、从哪个渠道买、费率页里各项费用怎么算。

这些只是需求上的差异，不是收益高低的排名。真正下单前，仍要核对**目标指数是否一致，以及具体产品的费率、运作方式、流动性和实际跟踪效果**。

## 写在最后

回到最开始的问题：ETF和联接基金可以跟踪同一个指数，但你买入的不是同一种基金份额。它们的投资目标接近，**持有结构、交易规则和资金使用方式却不完全一样**。

所以，与其先问“哪个好”，不如先问：**我需要怎样使用这笔资金？**
