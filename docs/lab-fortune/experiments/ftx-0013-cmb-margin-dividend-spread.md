# FTX-0013 招商银行融资持有与股息利差验证实验

| 项目 | 内容 |
| --- | --- |
| 实验编号 | FTX-0013 |
| 实验状态 | 计划中，尚未确认首笔成交 |
| 制定日期 | 2026-11-14 |
| 实验标的 | 招商银行A股（600036.SH） |
| 买入资金来源 | 100%融资买入 |
| 初始计划 | 100股起，允许分批建仓 |
| 资金上限 | 当前持仓买入成本及未偿融资本金均不超过50,000元 |

## 一、实验背景

融资买入股票，需要承担融资利息。

如果买入一家长期实施现金分红的上市公司，获得的股息收入能否覆盖对应的融资成本？

例如，以招商银行2025年度每股分红为参考，按2026年11月13日收盘价计算，静态含税股息率约为4.70%。如果融资利率为4%，两者之间存在约0.70个百分点的差额。

但这样的静态比较，并不能证明真实投资一定能够盈利。

未来分红可能变化，融资成本取决于真实负债和占用天数，股价波动也可能远大于股息与融资利息之间的差额。

此前的 [FTX-0012：520550融资持有与月度分红复投实验](/lab-fortune/experiments/ftx-0012-520550-margin-dividend-reinvestment)，主要观察现金分红复投与份额增长。实际观察中出现分红金额调整，因此需要重新审视原有假设。

FTX-0013不要求分红复投，也不假设未来分红保持不变，而是直接记录实际股息收入与融资利息。

**核心问题只有一个：真实获得的现金股息，能否覆盖对应融资资金的利息成本？**

## 二、实验目标

本实验设立一个核心目标、两个辅助目标。

### 2.1 核心目标：股息覆盖融资利息

> 全部使用融资资金买入招商银行后，实际收到的现金分红能否覆盖对应融资负债产生的利息？

基本计算方式：

```text
累计净分红
= 累计已到账应发分红 - 累计已扣缴红利税

累计融资利息
= 累计已支付利息 + 截至统计日的应计未付利息

累计股息利差
= 累计净分红 - 累计融资利息

股息覆盖率
= 累计净分红 ÷ 累计融资利息
```

股息利差大于零，或者覆盖率超过100%，表示在对应统计口径下，累计股息收入已经覆盖融资利息。

由于部分红利税可能在卖出时才扣缴，本实验同时保留实际税负和潜在税负两套口径，详见第四节。

### 2.2 辅助目标一：综合投资收益

股息覆盖融资利息，并不意味着整个投资盈利。

因此，除现金分红和融资利息外，还需要统计已实现买卖价差、当前持仓市值、浮动盈亏及交易费用。

这一目标回答：

**截至统计日，整个融资投资实验实际盈利或亏损多少？**

综合投资结果与股息覆盖结果分别评价，不互相替代。

### 2.3 辅助目标二：融资负债变化

本实验允许分批融资买入、主动偿还融资本金、卖出后重新融资买入。

融资负债变化会影响后续利息成本。

因此，需要持续观察真实融资本金、利率、占用时间与累计利息的变化，具体字段统一在第五节定义。

这一目标不要求按照固定计划还本，只记录真实变化及其影响。

## 三、核心假设与参考测算

### 3.1 核心假设

> 在适当的买入价格、实际融资利率及未来分红条件下，融资持有招商银行可能形成正的股息现金利差。

该假设仅针对股息现金流与融资利息之间的关系，不包含股价上涨或综合投资盈利的预期。

### 3.2 历史分红参考

根据招商银行公布的2025年度分红信息：

| 分红项目 | 每股分红（含税） | A股派息日期 |
| --- | ---: | --- |
| 2025年中期分红 | 1.013元 | 2026-01-16 |
| 2025年末期分红 | 1.003元 | 2026-07-10 |
| **2025年度合计** | **2.016元** | — |

以上数据已与招商银行官方分红记录及相关A股分红派息实施公告核对。

需要区分分红所属年度和实际派息日期。

本实验按**现金实际到账日期**统计股息收入，不将已宣告但尚未到账的分红提前计入累计收入。

### 3.3 买入价格与静态测算

此前提出过41元的假设买入价格。

2026年11月13日，招商银行A股收盘价为42.93元。

**42.93元来自行情平台，已与另一平台交叉核对，未经交易所官方历史数据核验。**

同时保留41元的原始设想和42.93元的市场价格作为参考。

假设买入100股，全部使用融资资金，融资年利率4%，未来年度每股分红仍为2.016元。

| 指标 | 41元假设价 | 42.93元参考价 |
| --- | ---: | ---: |
| 买入100股成本 | 4,100元 | 4,293元 |
| 参考年度含税分红 | 201.60元 | 201.60元 |
| 参考年度融资利息 | 164.00元 | 171.72元 |
| 税前股息利差 | +37.60元 | +29.88元 |
| 静态含税股息率 | 4.92% | 4.70% |
| 与4%融资利率差额 | +0.92个百分点 | +0.70个百分点 |
| 与4.5%融资利率差额 | +0.42个百分点 | +0.20个百分点 |

本表假设融资本金和利率全年不变，且全年实际分红与历史参考金额相同。

未考虑融资保证金要求、实际融资可用额度、佣金、最低收费、红利税及股价变化。

实际融资买入金额、融资成本和成交结果均以券商记录为准。

### 3.4 静态股息率盈亏平衡价格

若年度每股现金分红保持2.016元，融资年利率为4%，则：

```text
参考盈亏平衡股价
= 每股年度分红 ÷ 融资年利率

2.016 ÷ 4% = 50.40元
```

考虑不同税负：

| 假设税率 | 对应静态盈亏平衡价格 |
| --- | ---: |
| 0% | 50.40元 |
| 10% | 45.36元 |
| 20% | 40.32元 |

计算方式：

`盈亏平衡价格 = 每股含税分红 × (1 - 税率) ÷ 融资年利率`

20%属于短期持有可能面临的较高税负情景，并非长期持有的默认税率。

对于持股期限超过一年的合格股份，按照本方案制定时的税收政策，股息红利暂免征税。

表中价格仅代表静态股息率与融资利率相等的位置，不是股票整体投资的保本价格或买卖信号。

### 3.5 参数敏感性

以42.93元为参考价格，分别假设年度分红减少以及融资利率上升。

下表单位为百分点，表示静态含税股息率减去融资年利率。

| 每股年度分红假设 | 4%利率 | 4.5%利率 | 5%利率 |
| --- | ---: | ---: | ---: |
| 2.016元（不变） | +0.70 | +0.20 | -0.30 |
| 1.8144元（下降10%） | +0.23 | -0.27 | -0.77 |
| 1.6128元（下降20%） | -0.24 | -0.74 | -1.24 |

表中股息率均按42.93元计算，仅作静态参考，未考虑红利税。

实际结果必须使用真实分红和融资利息进行验证。

## 四、实验规则

### 4.1 资金来源与仓位上限

本实验所有股票买入，必须通过真实融资委托完成。

具体规则：

1. 实验标的仅为招商银行A股（600036.SH）。
2. 首次计划买入100股，允许之后分批融资建仓。
3. 当前尚未卖出持仓对应的买入成交成本不得超过50,000元。
4. 当前归属于本实验的未偿融资本金不得超过50,000元。
5. **持仓成本上限与融资本金上限分别独立计算，任何一项超过50,000元均不得新增买入。**
6. 不主动使用场外新增资金购买本实验股票、偿还融资本金或支付融资利息。
7. 不要求持续满仓，不因为股价下跌而无限加仓。
8. 卖出后允许重新融资买入，历史累计成交金额可以超过50,000元。
9. 其他实验原则上不将招商银行交易混入FTX-0013；如存在同标的交易，必须能够通过成交批次及融资合约可靠区分归属。

股票市值因上涨超过50,000元，不视为突破持仓成本上限。

#### 融资买入凭证

本实验与其他实验共用信用账户，因此需要保留每笔融资买入的可核查记录。

每次买入后，记录融资成交明细、融资合约编号或其他能够证明融资资金来源的凭证；必要时保留融资委托截图。

信用账户中的担保品买入或现金买入，不自动属于融资买入。

如果券商实际使用账户现金完成交易，不能将其事后记录为100%融资买入。

### 4.2 长期持有与低频波段

本实验以长期持有为主，但不禁止主动卖出。

不以日内或隔日小价差做T作为主要交易方式。

如果持仓经过较长时间上涨，出现明显的阶段性机会，可以卖出并等待后续重新融资买入。

例如，融资50,000元买入招商银行，之后市值上涨至70,000元，可以根据当时的价格和市场情况决定是否卖出。

卖出后按券商实际规则处理融资负债，剩余利润只记录实际金额，不限制其最终用途。

之后是否重新建仓，由新的市场条件决定。

不要求卖出后必须以更低价格接回，也不设置固定止盈比例或强制最低持有期。

#### 交易前记录

每次主动买入或卖出前，应记录：

- 当前股价、持仓成本与融资利率；
- 参考股息率；
- 交易理由；
- 对仓位和融资本金的预计影响。

主动卖出前，还需要根据拟卖出股份的批次与持股期限，估算可能触发的红利税，并比较卖出与继续持有的税负差异。

**上述税负测算写入在线表格的“交易前记录”，包括预计税额、税率档位以及相对于继续持有的税负差异。**

卖出后再记录券商实际扣缴税额、扣缴日期及与事前估算的差异。

实际成交及税费结果在交易后补充，不事后修改原始交易理由。

### 4.3 分红、还本与资金使用

本实验不要求现金分红复投，也不指定分红必须用于特定用途。

分红可以保留、支付融资利息、主动偿还部分或全部融资本金，或按实际需要进行其他安排。

卖出股票也可能发生融资负债偿还。

这些行为只记录真实资金与负债变化，不追踪共享信用账户内每一元现金的最终用途。

**偿还融资本金不属于投资费用，也不属于盈利。**

还本后，后续融资利息按照新的实际融资本金继续计算。

如再次买入本实验股票，仍须通过真实融资委托完成。

### 4.4 共用信用账户与利息归属

FTX-0013与其他实验共用同一个信用账户。

不同实验的现金、保证金和负债由券商统一管理，本实验不建立独立现金池。

券商每月从信用账户可用资金中自动扣收融资利息。

这种扣款属于券商正常的被动扣息行为，不要求追踪被扣资金具体来自哪笔分红或交易。

本实验不主动使用场外新增资金还本或付息，券商依据既定机制执行的自动扣息属于允许的正常操作。

#### 按标的识别融资利息

券商每日融资利息明细包含证券代码，因此可以根据600036识别招商银行对应的融资利息。

记录：

- 每日应计融资利息；
- 每月实际扣收的融资利息；
- 截至统计日的应计未付利息；
- 对应融资合约和未偿本金；
- 实际融资利率及调整日期；
- 本金偿还、到期和展期。

已付利息与应计未付利息不能重复累计。

如存在其他实验同时交易600036，应进一步通过融资合约和交易批次区分，无法可靠归属的部分不得直接计入本实验。

### 4.5 红利税与两套统计口径

按照方案制定时适用的A股个人投资者股息红利差别化税收政策：

| 持股期限 | 实际税负 |
| --- | ---: |
| 1个月以内（含） | 20% |
| 超过1个月至1年（含1年） | 10% |
| 超过1年 | 暂免征税 |

免税条件是持股期限**超过一年**，不是恰好一年。

对于持股一年以内的相关分红，派息时通常暂不扣税，转让股票时按最终持股期限计算扣缴。

卖出股份的持股期限按照证券账户先进先出原则计算。

上述税率依据财税〔2015〕101号。持股期限、先进先出及其他操作事项结合财税〔2012〕85号执行，其中2012年文件的旧税率档已由2015年政策调整。

实际发生卖出和复盘时，应重新核对当时适用的税收政策。

#### 分红、批次与税额关联

为了避免分批交易造成税额计算错误，在线表格需要保留分红事件与对应持股批次的关联关系。

每次分红按股权登记日日终实际持有的股份及对应批次，记录：

- 分红事件；
- 股权登记日；
- 对应买入批次；
- 参与分红股数；
- 每股分红及应发金额；
- 已实际扣缴税额；
- 尚未结税部分的潜在税额。

部分卖出时，根据证券账户适用的先进先出规则，将卖出的股份与历史买入批次及对应分红关联。

**潜在税额按相关分红事件及持股批次逐笔计算，不直接以整体持仓数量乘以统一税率估算。**

最终实际补税金额以证券登记结算机构及券商在卖出后的真实结算记录为准。

#### 口径A：实际已扣税口径

```text
累计净分红A
= 累计已到账应发分红
- 累计已扣缴红利税

股息利差A
= 累计净分红A - 累计融资利息

覆盖率A
= 累计净分红A ÷ 累计融资利息
```

口径A反映截至统计日的实际已扣税情况。

#### 口径B：当前卖出假设下的税后口径

对尚未最终结税的相关分红，假设在统计日卖出对应股份，按各批次截至统计日的持股期限估算税负。

| 持股期限 | 情景税率 |
| --- | ---: |
| 1个月以内（含） | 20% |
| 超过1个月至1年（含） | 10% |
| 超过1年 | 0% |

```text
累计净分红B
= 累计已到账应发分红
- 累计已扣缴红利税
- 尚未结税部分的情景潜在税额

股息利差B
= 累计净分红B - 累计融资利息

覆盖率B
= 累计净分红B ÷ 累计融资利息
```

计算时：

1. 已经实际扣缴的税款不得重复计算。
2. 已完成税务结算的分红使用实际税额，不再按假设税率计算。
3. 相关股份持股期限超过一年、按照现行政策符合免税条件的，情景税率为0%。
4. 不同买入批次对应的分红和持股期限分别核算。
5. **口径B统一假设在本次统计截止日卖出相关未结税股份。**
6. 实际补缴税额以券商真实结算为准，不以情景估算替代。

两套口径均为阶段复盘必报指标。

口径B仅用于评估假设当前卖出时的潜在税务影响，不代表已经发生的现金支出。

### 4.6 交易费用

所有买卖成交金额按成交价格乘以数量记录。

佣金、印花税、过户费等费用单独记录。

已实现交易价差采用扣除交易费用前的金额计算，相关费用在综合盈亏中统一扣除。

红利税计入分红税费，不再重复计入卖出交易费用。

费率及其变化以券商真实记录为准。

### 4.7 融资风险与内部行动线

FTX-0013与其他实验共用信用账户，融资风险并不独立。

《上海证券交易所融资融券交易实施细则》要求证券公司对客户担保物进行整体监控，并与客户约定维持担保比例要求。

**实际执行以券商与投资者签订的融资融券合同、有效业务规则及账户通知为准；交易所细则作为制度背景和最低规范参考。**

其他实验的亏损，也可能影响本实验的融资条件。

#### 建仓前需要确认的参数

| 项目 | 要求 |
| --- | --- |
| 券商维持担保比例预警线 | 建仓前确认实际值 |
| 券商最低维持担保比例要求 | 建仓前确认实际值 |
| 券商强制处置条件 | 建仓前确认 |
| 内部暂停新增融资线 | 依据券商预警线预留缓冲 |
| 内部减仓或还本行动线 | 在风险触发前确定 |
| 融资合约期限及展期规则 | 以真实合约为准 |

不预先编造具体百分比。

首次建仓前，应依据券商实际规则确定内部风险行动线，并保留制定日期。

执行原则：

- 接近内部暂停融资线时，暂停新增融资买入；
- 触及内部减仓或还本行动线时，按预先记录的方式处理风险；
- 不为了维持本实验而主动从场外追加资金；
- 发生券商追保、限制交易或强制处置时，按照真实情况处理并记录。

后续如果账户条件或券商规则发生变化，可以调整内部行动线，但必须保留调整原因、日期及历史版本。

| 事件类型 | 主要记录内容 |
| --- | --- |
| 融资买入 | 日期、股数、价格、金额、融资合约凭证 |

| 分红批次关联 | 分红事件、买入批次、参与股数、自行计算的税额、券商实际扣税记录及差异说明 |

每次相关交易、分红、融资本金或利息发生变化时，及时更新。

### 5.2 核心统计指标

| 指标 | 计算含义 |
| --- | --- |
| 累计到账应发分红 | 实际到账分红对应的含税总额 |
| 累计已扣缴红利税 | 已经真实发生的税款 |
| 潜在红利税 | 统计日假设卖出、按批次估算的尚未结税金额 |
| 累计融资利息 | 累计已付利息加当前应计未付利息 |
| **股息利差A** | 实际已扣税口径 |
| **覆盖率A** | 累计净分红A÷累计融资利息 |
| **股息利差B** | 当前卖出假设的税后口径 |
| **覆盖率B** | 累计净分红B÷累计融资利息 |

融资利息为零时，覆盖率不计算。

各指标应使用相同的统计截止日期。

### 5.3 综合投资收益

```text
综合投资盈亏
= 累计已实现交易价差
+ 当前持仓浮动盈亏
+ 累计净分红
- 累计融资利息
- 累计交易费用
```

其中：

- 已实现交易价差使用未扣交易费用的买卖金额计算。
- 当前浮动盈亏等于持仓市值减去未卖出股票的买入成本。
- 累计净分红默认使用实际已扣税口径A。
- 如需考虑潜在红利税，另列口径B下的情景综合盈亏。

如果全部清仓，当前浮动盈亏归零，历史已实现收益继续保留。

偿还融资本金不计入投资费用。

### 5.4 融资负债与持仓变化

| 指标 | 含义 |
| --- | --- |
| 累计融资发生金额 | 历史融资合约本金增加额 |
| 累计偿还本金 | 已经实际偿还的本金 |
| 当前未偿融资本金 | 尚未偿还的融资负债 |
| 当前融资年利率 | 实际适用利率 |
| 累计融资利息 | 本实验已发生的全部融资利息 |
| 当前持仓股数 | 实际持有的招商银行股份 |
| 当前持仓成本 | 尚未卖出股份的买入成本 |
| 当前持仓市值 | 当前股数乘以市场价格 |
| 当前浮动盈亏 | 当前市值减当前持仓成本 |

#### 有融资与无融资期间的拆分

为了避免主动还本后利息下降，使全周期股息覆盖情况显得过于乐观，增加以下辅助统计：

| 指标 | 说明 |
| --- | --- |
| 有融资负债期间的分红 | 登记日存在本实验未偿融资本金时，对应持仓取得的分红 |
| 有融资负债期间的利息 | 本实验实际存在融资负债期间发生的融资利息 |
| 有融资负债期间的股息利差 | 上述分红减对应融资利息及税负 |
| 无融资负债期间的分红 | 登记日不存在本实验未偿融资本金时，对应持仓取得的分红 |
| 无融资负债期间的持仓天数 | 无本实验融资负债、但仍持有招商银行的天数 |
| 登记日未偿融资本金 | 每次股权登记日，本实验实际尚未偿还的融资本金 |
| **登记日融资成本占比** | **登记日未偿融资本金÷登记日持仓买入成本** |

> 登记日融资成本占比的分母采用登记日持仓买入成本，而不是持仓市值，以便与本实验50,000元持仓成本上限保持一致。该指标不等于信用账户整体维持担保比例。

划分规则：

1. 股权登记日只要存在本实验未偿融资本金，该次分红就归入“有融资负债期间”。
2. 即使仅剩少量未偿融资本金，也遵守上述分类，不人为按本金比例拆分实际收到的现金分红。
3. 同时展示登记日融资成本占比，以反映该次分红对应的负债规模。
4. 如果登记日持仓成本为零，融资成本占比不计算。
5. 该比例仅用于描述负债相对持仓成本的规模，不等于账户整体维持担保比例。

分红所属阶段按股权登记日状态分类；总现金分红仍按实际到账日记账。

这一拆分只是辅助分析。由于分红与计息时间不同，阶段拆分不构成严格的经济因果归因。

核心累计股息利差仍然按照本实验全周期真实分红和融资成本计算，不因拆分而重复计入。

## 六、阶段复盘与结论判定

### 6.1 实验期限

本实验不设置固定结束日期。

首次真实融资买入后开始记录。

可以按月、按年度或在重要事件发生后进行复盘，不要求清仓，也不要求重新建仓。

### 6.2 分红与融资利息的时间差异

融资利息通常逐日产生，而现金股息只在特定日期到账。

因此，阶段性覆盖率可能出现明显波动。

尚未收到分红时，融资利息可能已经持续累积；分红到账后，覆盖率又可能突然上升。

需要区分：

- **截至统计日的累计现金流结果**；
- **经过较完整分红周期后的阶段性覆盖表现**。

前者可以随时计算。

后者必须结合实际派息次数、持仓时间与融资负债情况解释。

### 6.3 滚动12个月观察

在数据足够时，增加滚动12个月股息利差：

```text
滚动12个月股息利差
= 过去12个月实际到账净分红
- 过去12个月实际发生的融资利息
```

统计时：

- 分红按照到账日期计入窗口。
- 利息按照真实计息日期计入窗口。
- 不人为剔除空仓时间。
- 融资本金已经偿还的时间段，不虚构融资利息。
- 实际税负口径A和情景税负口径B分别计算。

**滚动12个月口径B的潜在税额，统一按照窗口截止日假设卖出相关尚未结税股份，并依据截至该日各批次的实际持股期限计算。**

不能按照每笔分红到账日的持股期限估算，否则会与第四节定义的口径B不一致。

#### 阶段性结论的解释标准

如果滚动12个月窗口已经覆盖招商银行正常实施的中期及末期分红，并包含相应融资负债期间，可以称为较完整的年度股息覆盖观察。

如果尚未经历完整分红周期，则只表述为截至统计日的实际现金流结果。

如公司减少派息次数或暂停分红，仍应如实记录，不因未收到分红而延后披露不利结果。

#### 跨年度比较

**至少具备两个相邻、互不重叠的完整12个月观察窗口，且原始数据完整、可以可靠归属时，才进行跨年度覆盖能力比较。**

这里的“数据完整”指交易、分红、融资利息、还本及税费等相关流水能够准确记录和归属。

**空仓、主动还本、阶段性清仓以及融资负债归零，均属于真实实验状态，不构成数据不连续或样本无效。**

只有原始流水缺失、金额无法核实或数据无法可靠归属时，才需要标注数据完整性问题。

即使拥有两个窗口，也只能说明样本期内的表现，不能保证未来长期持续覆盖。

这只是结论表述标准，不要求实验必须运行两年，也不设置两年到期自动终止。



### 6.4 三类结论独立呈现

每次阶段复盘分别给出三类结果。

**结论一：股息覆盖情况**

- 实际税负口径A的股息利差及覆盖率；
- 当前卖出税负情景口径B的股息利差及覆盖率；
- 是否经历较完整的分红周期；
- 有融资负债期间的股息利差；
- 无融资负债期间的分红；
- 登记日融资本金与持仓成本的比例；
- 主动还本、空仓及税费结算对结果的影响。

**结论二：综合投资收益**

- 累计已实现交易价差；
- 当前浮动盈亏；
- 累计交易费用；
- 实际口径与必要的税负情景口径下的综合盈亏。

**结论三：融资负债变化**

- 当前未偿融资本金；
- 累计融资发生金额及偿还金额；
- 融资利率和累计利息变化；
- 主动还本、卖出和重新融资对成本的影响。

例如：

如果某次复盘得到：

- 股息利差A：+200元；
- 股息利差B：-50元；
- 综合投资盈亏：-3,000元。

则应分别说明：

> 截至本次复盘，实际已扣税口径下的股息已经覆盖融资利息，但如果按当前卖出情景计算潜在红利税，股息利差仍为负。同时，整个投资实验处于综合亏损状态。

不将三类结果合并为单一成功或失败判断。

若某个完整观察窗口的股息不足以覆盖融资利息，则明确记录该窗口内核心假设未成立。

这一结果不自动触发卖出或实验终止。

## 七、风险与实验边界

本实验主要存在以下风险：

1. **分红风险**：招商银行未来现金分红可能减少或暂停。
2. **融资成本风险**：融资利率或合约条件可能改变。
3. **股价波动风险**：股票价格下跌可能造成远大于股息利差的损失。
4. **红利税风险**：不同持股期限可能改变税后利差的正负。
5. **波段交易风险**：卖出后未必能够以更低价格重新买入。
6. **共享账户风险**：其他实验的负债或亏损可能影响整个信用账户的担保条件。
7. **融资合约风险**：融资可能到期、无法展期或触发券商风险处置。
8. **观察周期偏差**：短周期现金分红不足，不一定代表完整分红周期内无法覆盖。

执行时遵守以下原则：

- 不突破50,000元的持仓成本及融资本金上限；
- 不主动使用场外新增资金扩大实验仓位或偿还本实验融资；
- 不为了完成实验而强制买入或持有；
- 不无限加仓摊低成本；
- 每笔买入保留融资性质凭证；
- 每次主动卖出前检查并记录税费影响；
- 根据券商实际规则确定内部风险行动线；
- 不通过改变观察窗口掩盖不利结果；
- 不事后修改真实成交、资金流水或原始研究假设。
