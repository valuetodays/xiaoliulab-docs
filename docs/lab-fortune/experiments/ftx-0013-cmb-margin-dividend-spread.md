## 一、实验背景

### 1.1 从分红复投到股息利差

此前建立的[FTX-0012：520550融资持有与月度分红复投实验](/lab-fortune/experiments/ftx-0012-520550-margin-dividend-reinvestment)，主要研究使用融资资金建立持仓，再将现金分红用于增加ETF份额。

但在观察过程中，520550每份月度现金分红由0.004元下降至0.003元。

这一变化促使我开始关注一个新问题：

**如果长期持有一家持续支付现金分红的上市公司，实际获得的分红能否超过融资成本？**

这一思路可以形象地理解为“借鸡生蛋”。

与FTX-0012不同，FTX-0013不以分红复投、增加持有份额为目标，而是直接验证现金分红与融资利息之间的关系。

### 1.2 为什么选择招商银行

本实验选择招商银行A股（600036.SH）作为第一个研究对象。

根据招商银行2025年度报告：

| 指标 | 2023年 | 2024年 | 2025年 |
| --- | ---: | ---: | ---: |
| 基本每股收益（EPS） | 5.63元 | 5.66元 | 5.70元 |
| 年度每股现金分红（DPS） | 1.972元 | 2.000元 | 2.016元 |
| 现金分红比例 | 35.01% | 35.32% | 35.34% |

**数据来源：**《招商银行2025年度报告》第二章第2.1节及第五章第5.11.2节。

**核对日期：**2026-11-20。

表中的DPS按照分红所属会计年度统计，而不是按照现金实际到账的自然年统计。

招商银行公司章程中的普通股利润分配政策提出，在满足相应经营与监管条件下，原则上每年向普通股股东现金分红不低于当年归属于普通股股东税后净利润的30%。

这些历史分红记录及公司政策，是本实验选择招商银行的主要依据。

但历史分红不代表未来一定维持或增长。

本实验不对所有高股息股票进行排名，也不研究招商银行是否属于最优投资标的。

### 1.3 融资持有的研究边界

使用融资资金买入股票，需要持续支付融资利息。

如果实际取得的现金分红超过融资利息，就可能形成正现金利差。

但股票分红会伴随除息调整，实际市场价格也会波动。

因此，**股息利差为正，不等于股票投资的整体收益为正。**

FTX-0013只验证前者，不将两者混为一谈。

## 二、实验目的与核心假设

### 2.1 实验目的

本实验设立一个核心目标：

> 通过融资买入并长期持有招商银行A股，记录真实现金分红和融资利息，验证累计现金分红能否覆盖累计融资利息。

核心计算方式：

**累计实际净分红 = 累计到账现金分红 − 累计实际扣缴红利税**

**累计融资利息 = 累计已支付融资利息 + 当前应计未付融资利息**

**累计股息利差 = 累计实际净分红 − 累计融资利息**

**股息覆盖率 = 累计实际净分红 ÷ 累计融资利息**

累计融资利息为零时，不计算股息覆盖率。

股息利差为正，说明截至统计日，实际净分红已经覆盖融资利息；为负则说明尚未覆盖。

这就是本实验的核心评价标准。

### 2.2 核心假设

本实验提出以下假设：

> 在一定的买入价格、现金分红和融资利率条件下，长期融资持有招商银行可能形成正股息利差。

该假设不要求股价上涨，也不要求在一年或两年内得出长期结论。

实际分红和融资成本均以真实数据为准。

### 2.3 历史分红参考

招商银行已经实施的2025年度现金分红如下：

| 项目 | 每股现金分红（含税） | A股派息日期 |
| --- | ---: | --- |
| 2025年中期分红 | 1.013元 | 2026-01-16 |
| 2025年末期分红 | 1.003元 | 2026-07-10 |
| **2025年度合计** | **2.016元** | — |

本实验采用最近一个现金分红已经全部实施的完整会计年度，作为参考年度。

当前采用2025年度每股2.016元。

未来新的完整年度现金分红全部实施后，可以更新参考值，记录对应年度、金额和更新日期。

参考年度分红只用于买入前测算，实验结果始终使用真实到账金额。

### 2.4 参考测算

设计阶段优先观察招商银行41元以下的买入机会。

2026年11月13日，招商银行A股历史参考收盘价为42.93元。

41元是计划观察价格，不是实际历史成交价格。是否满足买入条件，应以建仓前核查的市场价格为准。

假设买入100股，全部使用融资资金，**参考融资年利率4%**，每股年度现金分红仍为2.016元：

| 指标 | 41元假设价 | 42.93元历史参考价 |
| --- | ---: | ---: |
| 买入100股成本 | 4,100元 | 4,293元 |
| 参考年度现金分红 | 201.60元 | 201.60元 |
| 参考年度融资利息 | 164.00元 | 171.72元 |
| **参考年度股息利差** | **+37.60元** | **+29.88元** |
| 参考股息率 | 4.92% | 4.70% |
| 与4%融资利率的差额 | +0.92个百分点 | +0.70个百分点 |

以上为静态测算，假设融资金额及利率全年不变，未来获得与参考年度相同的现金分红。

实际结果受到买入日期、股权登记日、融资占用天数及真实分红金额影响。

该表不代表首笔融资买入后的第一年必然取得相同股息利差。

**4%是实验方案的统一测算利率，不代表实际融资合约利率。**

正式交易时，记录券商实际融资利率，并按照真实融资利息计算结果。实际利率变化不需要覆盖本节的历史参考测算。

### 2.5 长期成本股息率

除了每次买入时的参考股息率，本实验还可以观察长期持仓的成本股息率。

例如：

假设以40元买入股票，每股年度分红为2元，对应成本股息率为5%。

如果未来每股年度分红增长至2.4元，而持仓买入成本保持不变，则成本股息率提高至6%。

这一指标用于观察每股分红相对于实际买入成本的变化。

但是否形成正股息利差，始终由真实现金分红和融资利息决定。

## 三、实验前置条件

### 3.1 资金与持仓规模

本实验当前阶段融资买入成本上限为30,000元。

原则上每次融资买入100股，根据实际价格和剩余预算逐步建仓。

不限制累计买入次数和持仓股数，也不要求使用全部预算。

未来如调整资金上限，应记录调整日期及原因。

### 3.2 买入计划

本实验原则上每次融资买入100股。

不设置固定买入日期、加仓间隔或必须完成的建仓次数。

买入时主要考虑：

- **股票价格**：当前优先观察41元以下的买入机会，但不机械执行。
- **参考股息率**：根据最近完整年度每股分红与当前价格计算。
- **融资成本**：方案按4%测算，实际买入以真实融资利率为准。
- **剩余预算**：新增100股后，当前持仓买入成本仍不得超过30,000元。

实际是否买入，由当时的判断决定。

即使价格进入观察区间，也可以选择不买入。

不因股价下跌而要求必须加仓。

### 3.3 融资条件

本实验使用已有信用账户，与其他投资共用账户资产和融资额度。

首次买入前确认实际融资利率、融资额度以及合约期限。在实验记录表中记录券商适用的预警维持担保比例、强制处置条件及当前账户维持担保比例。同时记录自己采用的预警缓冲范围。当账户维持担保比例进入该范围时，暂停新增融资。具体数值以券商实际规定及建仓前记录为准。

本实验不另行设置复杂的内部维持担保比例行动线，也不制定基于招商银行股价跌幅的机械止损规则。

券商合同、融资到期及账户处置要求仍然需要遵守。

### 3.4 实验启动

本实验以第一笔真实融资买入成交作为正式启动日期。

首笔成交后记录：

- 成交日期；
- 成交价格和数量；
- 成交金额；
- 融资合约编号或可核实的融资标识；
- 实际融资利率。

未出现合适买入机会时，实验可以继续保持计划中状态。

## 四、实验方案与执行规则

### 4.1 分批融资买入

本实验使用融资资金买入招商银行A股。

每次原则上买入100股。

买入前根据股票价格、参考股息率、实际融资利率及剩余预算决定是否新增持仓。

不要求按照固定价格间隔加仓，也不要求在规定时间内完成建仓。

每次买入都必须满足第三章的资金限制。

### 4.2 长期持有

本实验以长期持有为基本方向。

不主动进行日常做T，也不以短期买卖价差作为实验目标。

不设置固定卖出日期。

实验可以持续多年。

如果股票价格下跌，但融资合约和账户条件允许继续持有，本实验不要求因为股价浮亏而终止。

如未来实际卖出股票，应记录相关操作，但不将买卖价差作为本期评价指标。

### 4.3 现金分红

每次现金分红记录：

- 分红所属年度；
- 股权登记日；
- 现金到账日期；
- 每股分红；
- 参与分红股数；
- 实际到账金额；
- 已实际扣缴的相关税款。

本实验不要求分红复投。

现金分红进入共用信用账户后，按照实际资金结算情况处理。

本实验只记录实际取得的现金分红，不追踪每一元分红的最终用途。

### 4.4 融资利息

本实验根据券商真实计息记录核算融资利息。

主要记录融资本金、实际利率、计息日期、利息金额、已付利息与应计未付利息。

已支付利息不得与应计未付利息重复累计。

本实验与其他投资共用信用账户，利息应按照融资合约等记录可靠归属。

无法确认归属的金额，应单独说明，不直接计入实验结果。

### 4.5 还本与卖出

如未来发生还本、融资合约到期、股票卖出或其他融资负债变化，应记录操作日期、金额、相关股数及融资合约。

偿还融资本金不是投资费用。

如果融资负债归零但仍持有股票，应记录该变化，并在复盘时区分有融资与无融资的持有期间。

### 4.6 交易费用与规则调整

买卖佣金、印花税及其他实际交易费用单独记录。

核心股息利差只比较实际净分红和融资利息，不将交易费用或交易价差混入该指标。

如果未来调整资金预算、持仓上限、融资渠道或买入方式，应记录调整日期、原规则、新规则及原因。

已经发生的真实成交和资金流水不得事后修改。

## 五、实验范围与边界

### 5.1 本期研究内容

FTX-0013主要研究：

- 实际融资买入多少股招商银行；
- 买入价格、成本及持仓变化；
- 实际收到多少现金分红；
- 实际发生多少融资利息；
- 融资本金和融资利率如何变化；
- 累计股息利差及覆盖率如何变化。

本实验不研究股票价格涨跌产生的投资盈亏，不设置基于持仓浮亏的评价标准。

### 5.2 实际异常事件

虽然不将股价盈亏纳入实验评价，但以下实际事件仍需记录：

- 融资利率发生变化；
- 融资合约到期或无法展期；
- 券商要求偿还融资本金；
- 股票被实际处置；
- 招商银行减少或暂停现金分红；
- 其他导致持仓、融资负债或现金分红变化的事件。

这些事项按实际发生情况记录，不预先为每一种情景设计复杂规则。

### 5.3 实验结束

本实验不设置固定结束日期。

如未来决定停止研究，或实际融资条件无法维持，可以结束实验。

结束时统计全部实际净分红、累计融资利息和最终股息利差，并说明期间发生的主要操作。

不以股票价格盈亏作为实验成功或失败的标准。

**每次发生操作或现金流事件时及时记录，不要求每天人工填写没有变化的数据。**

### 6.2 核心统计指标

| 指标 | 计算方式 |
| --- | --- |
| 累计到账现金分红 | 实际到账现金分红合计 |
| 累计实际净分红 | 累计到账分红－累计已扣缴红利税 |
| 累计融资利息 | 累计已付利息＋当前应计未付利息 |
| **累计股息利差** | **累计实际净分红－累计融资利息** |
| **股息覆盖率** | **累计实际净分红÷累计融资利息** |

累计融资利息为零时，不计算覆盖率。

各指标采用相同统计截止日期。

### 6.3 红利税处理

本实验以长期持有为基本方向，不主动进行短期波段交易。

按照方案制定时适用的A股个人投资者股息红利差别化税收政策，持股超过一年，相关股息红利暂免征收个人所得税。

持股一年以内（含一年）的股份，在派息时暂不扣缴个人所得税；如果后续卖出，再按照实际持股期限结算税款。

本实验以长期持有并满足现行免税条件作为基本假设。

如果实际发生红利税扣缴，应记录真实金额、日期及对应分红。

**补税后，在下一次复盘中单列补税金额，并更新累计净分红、股息利差及覆盖率；保留此前已经发布的复盘结果。**

本实验不对尚未发生的短期卖出税负进行复杂情景测算。

### 6.4 成本股息率

成本股息率作为辅助观察指标：

**成本股息率 = 参考年度每股分红 × 当前持仓股数 ÷ 当前未卖出持仓的买入成本**

如果分批买入，使用对应的实际持仓成本。

参考年度每股现金分红变化时，更新参考值并保留历史记录。

成本股息率不能代替实际股息利差。

核心实验结果仍然取决于真实现金分红与融资利息。

---

## 七、实验周期与阶段复盘

### 7.1 实验期限

本实验不设置固定结束日期。

正式记录从第一笔实际融资买入成交开始。

首次正式复盘安排在首笔成交满一年时。

一年只是观察节点，不代表实验到期。

此后可以继续长期观察。

### 7.2 分红周期

融资利息根据真实融资负债持续产生，而现金分红只在特定日期到账。

因此，阶段性股息覆盖率可能存在明显波动。

根据招商银行2026年半年度报告，2026年度中期利润分配计划安排于2027年1月至2月实施，具体股权登记日和派息日期以正式公告为准。

实验能否获得某次分红，取决于实际持仓及对应的股权登记日。

首次复盘时，应说明实际经历的分红周期，避免将尚未收到分红时的阶段性负利差误认为长期结论。

### 7.3 阶段复盘

首笔成交满一年后，使用第八章的模板进行正式复盘。

主要核对实际买入、现金分红、融资利息及期间发生的操作。

复盘不要求清仓，也不要求改变持仓。

后续数据充分时，可以增加滚动12个月股息利差观察，仍使用第六章的统一计算口径。

### 7.4 阶段结论

| 股息覆盖率 | 阶段结论 |
| --- | --- |
| 超过100% | 实际净分红超过融资利息 |
| 等于100% | 实际净分红等于融资利息 |
| 低于100% | 实际净分红尚未覆盖融资利息 |
| 累计融资利息为零 | 覆盖率不适用 |

阶段覆盖率低于100%不要求立即结束实验。

长期观察的目的，是积累不同分红周期、买入成本和融资条件下的真实数据。
