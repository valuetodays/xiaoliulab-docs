# 从历史峰谷回撤到分层加仓：深度回撤实验的参数设计-V2

> **状态：设计中**
>
> 本文记录 [FTX-0003](/lab-fortune/experiments/ftx-0003-a-share-deep-drawdown-recovery-experiment) 的参数设计方案 V2。
>
> [方案 V1](./parameter-design-v1)已退役，原文继续保留。


本文档是 **[FTX-0003 A股深度回撤修复实验](/lab-fortune/experiments/ftx-0003-a-share-deep-drawdown-recovery-experiment)** 的参数设计与研究依据。

## 1. 为什么形成方案 V2

方案 V1 以固定 Anchor 为核心：

- 使用 Anchor 衡量市场回撤；
- 根据相对 Anchor 的回撤幅度决定启动；
- 根据相对 Anchor 的回撤 Level 决定后续加仓。

这种设计的问题，不在于某一个百分比设置得不够准确，而在于 Anchor 同时承担了多个不同职责。

实际交易经历提供了一个直接反例。

白酒 ETF 的重要高点形成于 2021 年。2026 年开始关注这个方向时，它已经连续下跌约 5 年，相对此前高点回撤约 50%。

也正因为已经经历了这么长时间和这么深的下跌，我才开始认为这里进入了可以承担风险的位置，并在 **2026 年第一季度**分批入场。

即使从这个位置开始买入，后面仍然出现了明显浮亏。

这说明**上一轮重要高点可以很好地回答“市场已经跌了多深”，但不能单独回答“现在是否应该开始买入”。**

同样的问题也存在于后续加仓。

如果 START 本身已经发生在非常深的位置，继续按照 Anchor 每下降固定百分点设置买入档位，实际价格间距会越来越失真。

因此方案 V2 不再调整方案 V1 中的几个百分比，而是重新划分三个概念的职责。

## 2. 方案 V2 的三个核心概念

方案 V2 区分：

### Anchor

Anchor 是本轮深度回撤的市场状态基准。

它回答：**市场从上一轮重要高点已经跌了多深？**

计算方式：

$$
DD_{Anchor}=\frac{P_t}{P_{Anchor}}-1
$$

其中：

- $P_{Anchor}$ 为本轮下跌前确定的重要高点；
- $P_t$ 为当前价格。

Anchor 用于描述市场状态和历史比较。

Anchor 不直接决定买入。

---

### START

START 是本轮实验第一次真正承担风险的位置。

它回答：

> **现在是否已经出现了足够的证据，值得开始建立仓位？**

START 不对应固定的 Anchor 回撤百分比。

它可能发生在：

- Anchor -20%；
- Anchor -30%；
- Anchor -40%；
- Anchor -50%；
- 或更深的位置。

START 发生时，记录当时相对 Anchor 的回撤，但不预先规定 START 必须出现在哪一个回撤 Level。

当前计划：

> **START 首笔买入 100 股。**

100 股不代表已经确认市场见底。

它只表示当前证据已经足够让实验从纯观察状态进入真实持仓状态。

如果 START 后市场直接修复，接受只持有 100 股，不为了提高资金利用率追买。

---

### 局部回撤梯度

START 之后，不再使用 Anchor 回撤决定每一笔后续买入。

下一档价格以**上一笔实际买入价格**为基准。

若局部梯度为 \(g\)：

$$
P_{n+1}=P_n\times(1-g)
$$

当前主要候选值为 5%：

$$
P_{n+1}=P_n\times0.95
$$

于是执行过程变成：

```text
START
↓
再跌约 5%
↓
第 1 档
↓
再跌约 5%
↓
第 2 档
↓
……
```

局部梯度直接对应 START 后实际持仓继续产生的下跌幅度，不再依赖多年以前的历史高点计算。

## 3. 三个概念的职责边界

方案 V2 的主要变化可以概括为：

| 概念 | 负责回答的问题 | 是否直接触发交易 |
| --- | --- | --- |
| Anchor | 市场已经跌了多深 | 否 |
| START | 是否应该开始承担风险 | 是 |
| 局部回撤梯度 | START 后什么时候允许继续买 | 是 |

因此：

> **Anchor 是测量市场状态的坐标。**

> **START 是第一次承担风险的决策。**

> **局部回撤梯度是 START 之后的执行坐标。**

三者不再共用同一个百分比体系。

## 4. Anchor 的作用

Anchor 虽然不再承担买入触发职责，但仍然保留。

它主要用于：

- 判断当前是否已经进入历史意义上的深度回撤区域；
- 比较不同深度回撤发生时的市场位置；
- 记录 START 出现时市场已经下跌多少；
- 研究政策和资金事件通常发生在什么回撤阶段；
- 复盘不同市场周期。

例如未来可能记录：

| 事件 | Anchor 回撤 |
| --- | ---: |
| 首次明显稳市场表态 | -x% |
| 稳定资金痕迹明显增加 | -x% |
| START | -x% |
| 强政策确认 | -x% |
| 市场底 | -x% |

这里的百分比用于研究，而不是预先规定交易动作。

## 5. START 不再由固定回撤决定

方案 V1 容易产生一个问题：

> 为什么是 -30% START，而不是 -20%、-40% 或 -50%？

这个问题没有办法仅通过价格回答。

市场下跌到 -30%，只能证明市场已经下跌了 30%。

它不能证明：

- 政策环境已经发生变化；
- 有持续资金开始逆势进入；
- 市场风险已经进入值得承担的阶段。

因此方案 V2 取消：

> **固定 Anchor 回撤 = START**

START 改为根据多类证据共同判断。

## 6. START 前需要观察什么

目前重点观察三类信息：

### 市场位置

包括：

- Anchor 回撤幅度；
- 上证指数等主要指数绝对点位；
- 下跌持续时间；
- 本轮下跌速度；
- 成交额与成交量；
- 市场情绪和恐慌程度。

Anchor 回撤描述相对位置。

主要指数绝对点位用于保留当时真实的市场坐标。

两者都不单独决定 START。

### 政策信号

观察证监会、国务院金融监管部门、财政相关部门以及其他重要政策主体的公开信息。

重点不是单独保存某条新闻，而是判断政策状态是否发生变化，例如：

- 稳市场；
- 提振投资者信心；
- 活跃资本市场；
- 引导中长期资金入市；
- 鼓励机构提高权益配置；
- 更强的制度或资金安排。

政策用于判断市场环境是否开始发生变化。

### 资金痕迹

公开声明和实际资金痕迹分开观察。

重点包括：

- 510300 等核心宽基 ETF 份额变化；
- 159915 等代表性 ETF 份额变化；
- 5 日、20 日、60 日累计份额变化；
- 价格继续走弱时是否仍然持续出现份额增长；
- 是否有多只核心宽基同时出现逆势扩份额。

这里关注的不是资金身份，而是：

> **价格仍然偏弱时，是否持续有资金逆势进入。**

ETF 份额增加不能直接证明是谁在买，但可以作为资金实际进入市场的可观察痕迹。

## 7. 历史研究不能替代未来判断

历史复盘的作用不是寻找一个能够预测未来底部的固定公式。

此前研究已经看到：

- 有些政策出现以后，市场仍然可以继续明显下跌；
- 有些宽基 ETF 份额逆势增长以后，市场仍然可以继续深跌；
- 相似的市场位置，在不同年份之后的走势也可能完全不同。

因此历史数据只能帮助：

- 识别哪些状态值得观察；
- 发现哪些失败模式真实发生过；
- 估计 START 判断过早以后可能面对的风险；
- 为资金释放设计保留足够后手。

历史不是答案库。

它更接近：

> **反例库和风险边界库。**

方案 V2 不要求未来重复历史。

## 8. START 可能是一个确认过程

真实市场中，很难找到一个能够机械定义 START 的单一指标。

START 更可能来自多个证据逐渐收敛。

当前研究中的大致过程是：

```text
市场已经进入较深位置
↓
核心宽基 ETF 出现持续逆势资金痕迹
↓
政策环境开始出现支持性变化
↓
证据继续增强
↓
允许 START
```

2024 年 9·24 前后的历史提供了一个重要例子。

强政策公开以前，市场已经经历长期下跌，主要指数处于较低位置，同时核心宽基 ETF 已经持续出现逆势份额扩张。

因此方案 V2 不追求：

> 找到某一条新闻以后立即 START。

更关注：

> **在未来强确认出现以前，是否已经有足够证据允许用极小仓位开始试错。**

START 首笔 100 股正是为了处理这种不确定性。

## 9. START 后的三个风险

START 以后，执行规则需要同时处理三个方向的风险。

第一种情况是：

> **START 已经比较接近底部，市场没有继续深跌，很快开始修复。**

如果一直等待更低价格，可能最终只有 START 这一笔。

因此 START 必须先建立真实仓位。

第二种情况是：

> **市场继续下跌，但很快又发生反转。**

后续档位不能间距过大，否则中间可能长期没有新的买入机会。

第三种情况是：

> **START 判断明显偏早，市场继续出现 20%～30% 甚至更深的下跌。**

如果前几档释放资金过快，真正进入深水区以后反而没有资金。

因此方案 V2 的执行目标不是把每次行情都买到最多，而是同时做到：

```text
市场很快反转
→ 至少已经在场

市场继续正常下跌
→ 能逐步增加仓位

市场出现极深下跌
→ 仍然保留主要资金
```

## 10. START 后的局部价格梯度

当前主要候选局部梯度为：

**5%。**

START 后，每一次真实买入都会形成新的局部参考价格。

假设：

```text
START 成交价 = 4.000
局部梯度 = 5%
```

如果每一档都执行，则理论价格为：

| 阶段 | 理论触发价 | 相对 START 累计跌幅 |
| --- | ---: | ---: |
| START | 4.000 | 0% |
| 第 1 档 | 3.800 | -5.0% |
| 第 2 档 | 3.610 | -9.8% |
| 第 3 档 | 3.430 | -14.3% |
| 第 4 档 | 3.258 | -18.5% |
| 第 5 档 | 3.095 | -22.6% |
| 第 6 档 | 2.940 | -26.5% |
| 第 7 档 | 2.793 | -30.2% |

5% 当前仍是候选值，不冻结。

它的主要特点是：

- 不像 3% 那样容易形成过多档位；
- 不像 10% 那样使相邻买入距离过大；
- 7 个连续 5% 局部梯度可以把执行范围扩展到 START 后约 -30%。

## 11. 资金释放节奏

价格档位不直接规定必须买多少钱。

每一档首先定义的是：

> **当前最多允许累计使用多少风险本金。**

当前候选结构为：

| 阶段 | 相对 START 累计跌幅 | 累计风险本金上限 |
| --- | ---: | ---: |
| START | 0% | 100 股 |
| 第 1 档 | -5.0% | 5% |
| 第 2 档 | -9.8% | 10% |
| 第 3 档 | -14.3% | 20% |
| 第 4 档 | -18.5% | 35% |
| 第 5 档 | -22.6% | 55% |
| 第 6 档 | -26.5% | 75% |
| 第 7 档 | -30.2% | 100% |

这套节奏可以分为三个阶段。

### 前段：保证参与

```text
START：100 股
第 1 档：累计最多 5%
第 2 档：累计最多 10%
```

这一阶段主要处理 START 已经比较接近底部、市场很快修复的情况。

即使 START 偏早，前 10% 左右的继续下跌也只暴露少量风险本金。

### 中段：逐步增加风险

```text
第 3 档：累计最多 20%
第 4 档：累计最多 35%
```

市场已经从 START 再下跌约 14%～19%。

这说明 START 明显偏早，但价格已经进一步释放风险。

开始提高仓位，但仍然保留大部分本金。

### 深水区：释放主要资金

```text
第 5 档：累计最多 55%
第 6 档：累计最多 75%
第 7 档：累计最多 100%
```

只有市场从 START 再下跌超过约 20% 后，才开始释放主要风险本金。

如果 START 判断严重偏早，仍然能够把主要资金保留到更深的位置。

当前的：

```text
5%
10%
20%
35%
55%
75%
100%
```

仍然属于候选参数，不冻结。

## 12. 价格档位只负责开放额度

到达某一个价格档位，不代表必须立即把仓位增加到对应上限。

例如：

```text
当前到达第 4 档
累计资金上限 = 35%
```

它真正表示：

> **从现在开始，累计最多允许使用 35% 的风险本金。**

实际动作可以是：

```text
继续
→ 使用部分或全部新增额度

暂停
→ 保持当前仓位，不继续增加风险

终止
→ 本轮现货加仓停止
```

价格负责回答：

> **什么时候允许承担更多风险？**

证据状态负责回答：

> **现在是否真的要使用这些额度？**

资金上限负责回答：

> **无论多有信心，最多可以使用多少？**

因此：

```text
证据
→ 决定是否 START、是否继续

价格
→ 决定什么时候开放下一档

资金上限
→ 决定最多可以买多少
```

## 13. 不允许提前使用下一档额度

即使现场判断非常乐观，也不能因为政策突然增强、资金痕迹明显或者市场情绪快速修复，而提前使用下一档资金。

例如当前只到第 3 档：

> **累计风险本金最多使用 20%。**

即使此时判断非常有信心，也不能直接使用第 4 档的 35% 或更高额度。

新的价格下跌发生以后，才开放新的风险额度。

这条规则用于防止：

> **因为主观信心快速增强，在真正深跌发生以前提前把资金打完。**

## 14. 只有真实成交才能产生新的局部坐标

局部梯度始终以上一笔**实际成交价**为基准。

如果理论档位到达，但当时决定暂停，没有发生买入，则该理论价格不成为新的局部参考点。

例如：

```text
START = 4.000

理论第 1 档 = 3.800
价格到 3.800，但没有买入

之后跌到 3.700
重新评估后实际买入
```

下一档从 3.700 重新计算：

$$
3.700\times0.95=3.515
$$

而不是继续以没有发生真实成交的 3.800 为基准。

因此：

> **执行坐标来自真实成交，不来自理论计划。**

## 15. 不追买，不补档

如果某一档到达时没有执行，之后市场直接上涨，不为了补足计划仓位在更高位置买入。

如果 START 后直接上涨，也接受只持有 100 股。

如果只触发第 1 档以后市场开始修复，也接受只使用约 5% 的风险本金。

方案不要求：

> 每一次判断正确以后都必须获得最大收益。

它优先保证：

> **如果 START 判断错误，仍然有足够资金继续执行。**

因此低资金利用率本身不是执行失败。

## 16. 最后一档以后停止现货扩张

第 7 档以后，风险本金已经全部开放。

如果市场继续下跌：

- 不追加原计划之外的现货风险本金；
- 不因为浮亏扩大修改现货资金上限；
- 不为了降低成本无限向下加仓；
- 永久现金继续保留；
- 融资增强按照独立规则判断。

现货分层加仓系统到此结束。

## 17. 沪深300和创业板不一定需要不同的局部梯度

方案 V1 曾尝试直接根据不同指数的历史波动设置不同回撤 Level。

方案 V2 提出另一个可能：

> **不同指数可以使用相同的局部价格梯度，但使用不同的 START 判断和资金释放参数。**

例如两者都采用 5% 局部梯度，并不意味着风险模型完全相同。

仍然可以不同的是：

- START 所需证据强度；
- 每一档累计资金上限；
- 最大累计投入；
- 保留现金比例；
- 允许经历的档位数量；
- 融资增强规则。

这个问题仍需继续验证。

## 18. 当前候选执行参数

目前形成的候选方案为：

```text
START：
100 股

START 判断：
多证据人工确认，不使用单一固定阈值

局部梯度：
5%

后续档位：
7 档

累计风险本金上限：
5%
10%
20%
35%
55%
75%
100%
```

当前真正准备固定的是执行结构，而不是这些具体数字：

> **证据决定是否开始和是否继续。**

> **价格决定什么时候开放下一档。**

> **资金上限决定最多能够承担多少风险。**

## 19. 方案 V2 仍需解决的问题

当前已经明确的是模型结构和第一版执行候选参数，而不是最终方案。

仍需研究：

1. Anchor 的正式确定方法；
2. START 最低需要哪些证据；
3. 市场绝对点位在 START 判断中的作用；
4. ETF 份额等资金痕迹如何量化；
5. 如何区分短期申购和持续逆势资金进入；
6. 政策信息在 START 中应该承担多大权重；
7. 局部梯度最终采用 5% 还是其他数值；
8. 7 个后续档位是否足够；
9. `5/10/20/35/55/75/100%` 是否需要进一步调整；
10. 每一档到达以后，“继续 / 暂停 / 终止”的判断依据；
11. 沪深300与创业板是否采用相同局部梯度；
12. 融资增强从哪一个阶段启动；
13. 极端情况下需要保留多少永久现金。

这些问题通过后续历史研究和实际实验继续确定。

## 20. 与方案 V1 的关系

方案 V1 不是删除，而是退役。

方案 V1 的重要价值在于暴露了一个问题：

> **一个容易计算的指标，不一定应该同时承担状态描述、决策和执行三个职责。**

方案 V2 因此将：

```text
Anchor
START
局部回撤梯度
```

拆分为三个独立概念。

进一步研究以后，又增加了一个新的认识：

> **未来市场不存在一个能够可靠替代现场判断的固定规则。**

因此方案 V2 不再追求：

```text
一个指标
→ 一个阈值
→ 一个确定动作
```

而是固定：

```text
职责
风险边界
执行顺序
资金上限
```

同时允许未来现场证据决定是否继续承担风险。

方案 V1 的原始内容不再修改，另行通过[反思文档](./parameter-design-v1-retrospective)记录它为什么被推翻，以及从中得到的模型审查方法。

如果方案 V2 以后被新的证据推翻，也继续保留本文，并建立参数设计方案 V3。

## 21. FTX-0003 不是永久深度回撤模板

FTX-0003 针对的是**下一次实际发生的深度回撤**。

它不是所有未来深度回撤永久共用的模板。

本轮实验结束以后，将根据[FTX-0003 实验执行记录](./execution-log)中保存的：

- 实际 START 时点；
- START 时的市场位置；
- 当时的政策环境；
- ETF 份额等资金痕迹；
- 每一次实际加仓；
- 被跳过的理论档位；
- 每次继续、暂停或终止的理由；
- 最大持仓回撤；
- 资金使用情况；
- 市场最终修复过程；

重新评价方案 V2。

下一次深度回撤可以建立新的 FTX 实验，并基于 FTX-0003 的真实结果形成下一代方案。

整个演进过程仍然是：

```text
方案 V1
↓ 已退役
方案 V2
↓ 实际深度回撤验证
FTX-0003 执行结果
↓
方案 V3
↓
下一次独立 FTX 实验
```

每一代方案保留原始内容和独立路径，不覆盖上一代历史。
