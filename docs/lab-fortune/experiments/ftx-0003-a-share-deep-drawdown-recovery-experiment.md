## 实验目标

本实验研究的不是如何预测市场最低点，而是：

> **普通投资者能否在没有持仓压力、没有巨额浮亏、没有市场恐慌的时期，提前制定极端行情中的资金使用规则，并在真正出现深度回撤时按照预案执行。**

实验重点观察三个问题：

1. 在极端市场状态出现以前长期持有现金，是否能够形成实际优势；
2. 市场进入深度回撤后，事前制定的分层资金规则能否降低临场情绪对交易决策的影响；
3. 在自有资金现货之外，有限融资和小额 Call 是否能够在不明显破坏生存能力的情况下改善修复阶段的收益结构。

实验不要求买到最低点，也不把盈利作为唯一成功标准。

如果市场最终明显上涨，但实验过程中因为恐惧、犹豫或临场修改规则而未能执行原计划，该结果同样记录。

## 核心假设

普通投资者通常没有明显的信息、速度和组织优势，但可以选择不交易、长期持有现金并等待。

本实验假设：

> 在正常市场状态下减少不必要的主动交易，将现金和风险承受能力保留到极端行情；市场进入深度回撤后，再按照事前规则逐层承担风险，可能比长期保持高参与度具有更好的生存能力和风险收益结构。

“深度回撤”不由单一百分比定义。

实验启动时综合考虑：

- 主要宽基指数所处位置；
- 相对前期高点的回撤幅度；
- 下跌速度；
- 市场广度；
- 成交和情绪状态；
- 是否出现明显恐慌；
- 政策和市场环境。

实验启动依赖市场状态判断。

启动以后，价格档位负责开放风险额度，是否继续使用额度仍根据当时证据判断；风险边界和资金上限不因临场信心而放宽。

## 执行坐标与 START

### START

START 是本轮实验第一次真正承担风险的位置。

START 不对应固定的历史回撤百分比，而是在深度回撤环境中综合当时可观察到的市场、政策和资金证据后确定。

当前计划：

> **START 首笔买入 100 股。**

START 不代表已经确认市场见底，只表示当前证据已经足以允许小仓位试错。

START 成交以后，START 及后续每一笔真实成交共同构成本轮实验的执行坐标。

### 局部回撤梯度

START 之后，不再使用历史高点回撤决定后续买点。

后续价格档位以上一笔实际买入价格为基准。当前主要候选局部梯度为 5%：

$$
P_{n+1}=P_n\times0.95
$$

价格达到下一档，只表示开放更高的累计风险本金上限，不代表必须立即买满。

## 实验资金与执行方案

实验启动时：

$$
T=E+B
$$

其中：

- $T$：实验启动时可支配总资金；
- $E$：场外应急储备；
- $B$：证券账户启动资金。

证券账户启动资金拆分为：

$$
R=20\%\times B
$$

$$
C=80\%\times B
$$

其中：

- $R$：场内永久现金底仓；
- $C$：自有风险本金。

$R$ 原则上保持现金状态，不用于主动加仓。

### 自有资金现货主线

现货是本实验的主要策略。

当前计划使用：

- 510310：沪深300方向；
- 159915：创业板方向。

两只 ETF 独立判断 START，并在 START 后按照自身实际成交价计算局部回撤梯度。

当前候选执行结构为：

| 阶段 | 相对 START 累计跌幅 | 累计风险本金上限 |
| --- | ---: | ---: |
| START | 0% | 100 股 |
| 第 1 档 | -5.0% | 5% |
| 第 2 档 | -9.8% | 10% |
| 第 3 档 | -14.3% | 20% |
| 第 4 档 | -18.5% | 35% |
| 第 5 档 | -22.6% | 55% |
| 第 6 档 | -26.5% | 75% |
| 第 7 档 | -30.2% | 100% |

这些比例对应[参数设计方案 V2](/lab-fortune/experiments/ftx-0003-docs/parameter-design-v2)中的当前候选方案 B，尚未冻结，也不表示历史已经证明其最优。

价格档位只负责开放额度。到达某一档以后，可以继续、暂停或终止后续加仓，但不得提前使用下一档额度。

只有实际买入成交以后，才形成新的局部价格坐标。

如果某一档没有执行，之后价格上涨，不为了补足计划仓位追买。

第 7 档以后，自有风险本金已经全部开放；如果市场继续下跌，不因此增加计划外本金。

### 融资增强支线

融资是独立增强支线，当前计划主要使用：

- 510300：沪深300ETF。

融资同时受两个约束。

第一层是融资绝对上限：

$$
L_{\max}=mC
$$

其中 $m$ 为实验启动前最终确定的融资比例。

当前压力测试比较：

- 50%；
- 55%；
- 60%。

最终比例在实验启动前确定，并在启动时冻结。

第二层是担保比约束。

当前内部安全底线为：

> **担保比不得低于 300%。**

正式启动时，根据当时券商有效的预警线、追保线、强平线和融资规则重新确认。

融资额度与担保比约束同时生效，任一条件不满足即停止新增融资。

融资的具体启动时机和额度释放节奏不再绑定 V1 的固定历史高点回撤档位。

融资额度累计使用率仍表示允许使用的上限，不要求必须借满。正式规则在实验启动前结合 V2 现货执行结构另行确认。

担保品上涨、账户盈利和新增现金均不得提高已冻结的融资绝对上限。

### Call 尾部实验支线

Call 支线用于验证：

> **A股进入极度低迷状态后，期权市场是否可能低估随后快速反弹的概率。**

当前初步风险预算：

- 每月权利金风险预算不超过 100 元；
- 年度权利金预算不超过 1,200 元；
- 没有合适条件时可以不买；
- 当月盈利不增加后续月份风险预算；
- Call 盈利不增加现货本金；
- Call 盈利不增加融资额度。

具体合约剩余期限、虚实值程度和每月最大合约数量，在实验启动前继续研究。

Call 权利金允许全部损失，不承担主仓功能。

### 后续新增现金流

实验开始后新增的工资、投资收入或其他现金，只有实际到账后才计入可用资产。

新增现金：

- 不提前计入实验风险承受能力；
- 不提高已冻结的融资绝对上限；
- 不自动产生买入信号。

没有新的风险额度开放时，可以继续保持现金状态。

## 实验规则

### 现货执行规则

1. 不预测最低点；
2. 历史高点回撤只作为观察信息，不直接触发买入；
3. START 根据当时可观察到的市场、政策和资金证据判断；
4. START 首笔买入 100 股；
5. START 后价格档位只负责开放累计风险本金上限，不代表必须买满；
6. 不允许提前使用下一档额度；
7. 只有真实成交才能产生新的局部价格坐标；
8. 未执行的档位不在价格上涨后追买或补档；
9. 自有风险本金全部开放后，不因继续下跌增加计划外本金。

### 融资执行规则

1. 融资只作为增强支线；
2. 融资绝对额度在启动时冻结；
3. 不因账户盈利、新增工资或担保品上涨提高融资上限；
4. 同时满足融资额度和担保比约束；
5. 任一风险约束触发，停止新增融资；
6. 不为了完成计划而强制借满额度。

### Call 执行规则

1. 只使用预先确定的小额风险预算；
2. 权利金允许全部损失；
3. 不使用现货主线资金弥补 Call 损失；
4. Call 盈利不提高未来风险预算；
5. 手续费单独保留原始记录；
6. 只有市场处于符合条件的极端状态时才允许参与；
7. 市场明显进入修复阶段后停止新增此类尾部仓位。

### 实验外个人交易

实验期间允许使用少量个人资金进行实验外操作。

这些交易：

- 不属于本实验策略；
- 不影响实验既定风险边界；
- 不计入实验收益和亏损；
- 不提高实验融资额度；
- 不与实验资金互相补偿。

实验记录中注明：

> **实验期间存在实验外个人交易，不纳入本实验统计。**

## 风险控制

### 永久现金底仓

证券账户启动资金中的 20% 作为永久现金底仓，用于：

- 保留流动性；
- 增加极端行情缓冲；
- 提高融资账户生存能力；
- 防止实验资产全部暴露于市场风险。

永久现金底仓原则上不用于主动买入股票或 ETF。

### 融资绝对上限

融资绝对上限在实验启动时根据自有风险本金确定。

冻结后，不因以下因素上调：

- 账户上涨；
- 新增工资；
- 场外资产增加；
- 担保比提高。

### 担保比安全边界

当前内部压力测试底线：

> **担保比 ≥ 300%。**

真实启动时重新核对并记录：

- 预警线；
- 追保线；
- 强平线；
- 可充抵保证金证券折算规则。

### 计划外资金限制

深度回撤过程中，不因浮亏扩大而持续追加计划外资金。

实验允许判断错误和继续浮亏，但风险预算以启动时冻结的金额为边界。
