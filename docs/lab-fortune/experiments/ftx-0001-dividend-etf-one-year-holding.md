# FTX-0001 红利 ETF 一年持有实验

| 项目 | 内容 |
| --- | --- |
| 实验编号 | FTX-0001 |
| 实验状态 | 进行中 |
| 开始时间 | 2026-03 |
| 计划结束时间 | 2027-03 |
| 实验周期 | 365 天 |
| 实验标的 | 红利低波100ETF（563020）、红利低波ETF（515450） |
| 初始金额 | 约 20,000 元 |

## 实验目标

验证自己能否将一笔红利 ETF 组合持有满 1 年。

重点不是收益率，而是：

> 不管上涨、下跌、横盘，都尽量拿住，不因为短期市场变化主动卖出。

## 实验规则

1. 买入后持有 365 天。
2. 不因上涨止盈。
3. 不因下跌止损。
4. 不因其他品种上涨而换仓。
5. 不使用该笔持仓做 T 或波段交易。

## 成功标准

持有满 365 天，期间没有因为短期涨跌、情绪或市场热点主动卖出。

收益率不作为实验成功与否的判断标准。
