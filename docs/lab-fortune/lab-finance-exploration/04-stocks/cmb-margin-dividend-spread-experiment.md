# 我准备融资买入招商银行，只验证一件事：分红能否覆盖利息？

最近，我一直在研究现金分红。

最初关注的是一些高股息ETF，尤其是按月分红的产品。我曾经尝试过一个思路：通过融资建立初始持仓，再将收到的现金分红继续用于购买ETF，逐步增加持有份额。

但在观察过程中，我发现其中一只ETF的每份月度分红从0.004元下降到了0.003元（说的没错，就是520550）。

这让我开始思考一个问题：

**如果未来希望长期获得现金流，是不是应该更加关注企业本身的分红能力，而不只是当前的股息率？**

沿着这个问题，我准备开展一个新的实验。

这次的研究对象是招商银行A股（600036.SH）。

截至本文写作时，实验仍处于计划阶段，尚未开始实际建仓。

## 一、一个很简单的想法

假设有一家上市公司，每年能够提供5%左右的现金股息率。

而融资买入这家公司股票，需要支付的年化融资利率是4%。

那么，两者之间理论上就存在大约1个百分点的利差。

如果投入10,000元：

- 每年参考现金分红约500元；
- 每年参考融资利息约400元；
- 两者相差约100元。

**这只是为了说明计算关系而使用的整数假设，并不是招商银行的实际收益测算。** 招商银行基于历史分红的具体参考测算，会在下一节给出。

真实的现金分红并不固定，融资利率也可能变化。而且股票价格还有涨跌风险。

但它让我产生了一个值得验证的问题：

**如果真的使用融资资金买入一家持续分红的企业，长期下来，实际收到的分红究竟能不能覆盖融资利息？**

我不想只停留在计算器里的理论结果，而是准备用小规模真实交易，长期记录这个过程。

## 二、为什么选择招商银行？

我没有对市场上所有高股息股票进行完整排名。

选择招商银行，主要是因为我希望观察一家具有多年现金分红记录、能够通过公开财务报告持续跟踪的企业。

根据招商银行2025年度报告，最近三个会计年度的每股现金分红分别为：

| 分红所属年度 | 每股现金分红 |
| --- | ---: |
| 2023年 | 1.972元 |
| 2024年 | 2.000元 |
| 2025年 | 2.016元 |

以上按照**分红所属会计年度**统计，并非对应自然年内实际到账的分红。

这三年的每股现金分红有所增加，但增幅并不大。

未来是否继续增加，目前没有人能够保证。

我关注的也不是招商银行接下来会涨到多少钱，而是它未来实际支付多少现金分红，以及这些分红与我的融资成本之间是什么关系。

举一个具体例子。

假设以每股41元的价格融资买入100股招商银行，使用4%的参考年化融资利率。

那么：

| 项目 | 金额 |
| --- | ---: |
| 买入100股需要资金 | 4,100元 |
| 按2025年度分红计算的参考年分红 | 201.60元 |
| 按4%计算的参考年融资利息 | 164.00元 |
| **参考年度利差** | **+37.60元** |

这个数字看起来很小。

不过，我更关心的不是一年能不能得到这37.60元，而是当时间延长到三年、五年甚至更久时，真实结果会是什么样子。

需要注意，这个例子并不代表实际第一年就能收到201.60元分红。

能否参加分红取决于股权登记日，未来每股分红也可能发生变化。实际融资利息则根据真实融资金额、利率和占用时间计算。

## 三、我的实验规则只有几条

我不打算一开始就投入大笔资金。

这次给自己设定的第一阶段资金上限是 **30,000元**。

每次原则上只融资买入100股。

至于什么时候买入，主要观察股票价格、参考股息率和融资利率之间的关系。

如果价格合适，就买入100股。

如果没有合适机会，就继续等待。

不要求在规定时间内完成建仓，也不要求一定用完30,000元。

**只限制总金额：当前阶段融资买入成本不超过30,000元。每次原则上买入100股，具体能买多少股，取决于实际买入价格。**

另外，我还给这次实验设置了一个明确限制：

**不做T。**

这是因为我希望将短期交易与长期现金分红研究区分开来。

如果频繁买卖股票，最后即使获得了收益，也可能很难分清究竟来自交易价差，还是分红与融资利息之间的关系。

这次我希望尽量减少短期交易对实验的干扰，让真实现金流来回答问题。

## 四、这次我不研究股票涨跌，但融资风险仍然存在

假设我融资买入招商银行后，股价下跌了20%。

股票本身会出现持仓亏损，但融资持有的风险并不只是账面亏损。

因为我使用的是信用账户，还存在维持担保比例、融资合约期限以及券商风险处置等约束。

**如果账户触发券商预警、需要追加担保或被强制处置，原本计划长期持有的股票也可能被迫卖出，实验可能因此中断。**

所以，在实际建仓前，我会核查券商的预警和强制处置条件，以及整个信用账户的实际维持担保比例。

如果账户接近预警条件，就暂停新增融资。

这些属于实际操作必须面对的风险。

不过，本实验的评价指标仍然不包含股票价格涨跌。

如果招商银行股价下跌20%，不能仅凭这一点判定股息利差实验失败。

同样，如果股价上涨30%，也不意味着实验已经成功。

原因很简单：

**我研究的是现金分红能否覆盖融资利息，不是招商银行这笔投资的综合收益率。**

现金分红本身也不是凭空产生的利润。股票分红会伴随除息调整，所以现金股息超过融资利息，并不代表整个投资一定赚钱。

不评价股价盈亏，是研究范围的取舍；不代表忽视融资风险。

真正发生风险事件时，仍然需要作出相应决策，并如实记录它对融资负债、股票持仓和实验过程产生的影响。

## 五、真正重要的是长期记录

我计划记录每一次实际操作。

例如：

- 哪一天买入了100股，成交价格是多少；
- 使用了多少融资本金；
- 期间实际产生了多少融资利息；
- 哪一天收到现金分红，金额是多少；
- 如果发生还本、利率调整或卖出，又发生了什么变化。

最终计算两个指标。

**累计股息利差 = 累计实际净分红 − 累计融资利息**

**股息覆盖率 = 累计实际净分红 ÷ 累计融资利息**

其中，实际净分红按照真实到账现金分红扣除已实际发生的红利税计算。

如果分红超过利息，就记录正利差。

如果分红没有覆盖利息，就记录负利差。

我不会为了让结果好看而调整统计方式。

这次实验也没有固定结束日期。

一年后可以复盘，两年后可以继续，五年后如果仍然持有，也可以继续记录。

我希望通过持续积累真实数据，观察不同买入成本、分红水平和融资利率下的现金利差变化。

## 六、写在最后

我一直认为，个人投资有一个优势，就是可以按照自己的节奏做一些长期观察。

不一定要求每项研究都在短时间内获得结论。

这次实验，我没有准备复杂的交易模型，也没有设定很高的收益目标。

只使用30,000元作为当前阶段的资金上限，每次原则上买入100股，不做T，然后长期记录实际现金分红与融资利息。

最后能否形成正现金利差，现在并不知道。

但这正是实验存在的原因。

**不是因为已经知道答案才开始，而是希望通过真实记录找到答案。**
