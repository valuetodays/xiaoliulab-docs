# 关于我

我出生于1992年冬天，河南省周口市鹿邑县的一个村庄。

2010年，我进入大学，学习英语师范专业。虽然所学专业与计算机无关，但大学期间，我花了不少时间自学 C、C++、Win32 等编程技术。

2014年大学毕业后，我开始从事软件开发工作，先后在北京、南京和杭州生活、工作。

除了日常工作，我也一直在学习和尝试自己感兴趣的事情。

从最初研究证券市场中的价格差异，到后来探索做 T、程序化交易，再到逐步建立小刘实验室，这些事情没有一个预先制定好的完整计划，而是在不断尝试中慢慢发展起来的。

## 为什么记录这些经历？

2026年11月，我花了将近一整天的时间，重新回忆了从童年到现在的许多经历。

有些事情已经过去二三十年，记忆难免模糊；有些事情原本以为早已忘记，却在交谈过程中重新想了起来。

我发现，自己经历过的不少事情，其实从来没有认真记录过。

如果再过十年、二十年，也许会忘记更多细节。

所以，我想趁着现在还有印象，把它们逐渐整理下来。希望尽可能真实地记录自己曾经经历过什么、做过什么，以及当时是怎样想的。

## 持续记录

这里的内容不会一次写完。

我会先整理已经能够确认的经历，再根据新的回忆逐步补充。对于记不清的细节，会保留不确定性，而不是为了让故事完整就自行填补。

如果以后发现某段经历值得单独写成文章，也可以从现有内容中拆分出来。

过去已经发生，记录却可以继续。

希望多年以后再回过头看，还能从这些文字里找到当时的自己。
