# 微信 H5 支付支持情况

## 为什么没有 H5 支付实验

很多朋友会发现：

- Native Pay ✔
- JSAPI ✔
- Code Pay ✔

唯独没有 H5 Pay。

并不是因为实验室没有实现，而是当前微信支付的申请政策限制。


## 当前微信支付政策

根据微信支付官方申请规则：

> 个体工商户、小微商户暂不支持申请 H5 支付。

因此，当前使用个体工商户主体的小刘实验室暂时无法申请 H5 支付产品权限。

官方说明：[商户申请H5支付权限注意事项 - 腾讯客服](https://kf.qq.com/faq/211124JbyEFj211124aeY77F.html)


作者曾帮助朋友完成 H5 支付接入，并验证过 MWEB 支付流程。由于小刘实验室当前采用个体工商户商户号，根据微信支付现行申请规则，暂无法申请 H5 支付权限，因此本文暂不提供基于实验室商户的实测示例。待后续政策调整或主体条件满足后，将补充完整实验。


## 实验室目前已完成

目前已经完成验证：

✅ Native Pay

以上内容均经过真实商户验证。


## 为什么暂未提供 H5 支付实验

由于当前小刘实验室使用的是个体工商户商户号，根据微信支付现行申请规则，暂无法申请 H5 支付权限。

因此，实验室目前无法搭建一个可供读者亲自体验和验证的 H5 支付实验环境。

虽然网上可以找到不少 H5 支付示例代码，但由于无法提供真实商户环境，读者也无法完成整个实验流程，例如：

- 创建 H5 支付订单
- 获取并跳转 `mweb_url`
- 实际完成支付
- 接收支付回调
- 验证订单状态及异常场景

小刘实验室坚持：

> 所有实验均应支持读者从零开始完整体验和验证，而不仅仅是阅读示例代码。

因此，在获得 H5 支付权限之前，本文暂不提供 H5 支付教程。待后续政策调整或主体条件满足后，将补充完整实验。
